អំពីពន្ធលើអចលនទ្រព្យ

ស្វែងយល់អំពីការគណនា ច្បាប់ និងបទប្បញ្ញត្តិពាក់ព័ន្ធនឹងពន្ធលើអចលនទ្រព្យនៅក្នុងប្រទេសកម្ពុជា។

១. សេចក្តីសង្ខេបអំពីពន្ធ

ពន្ធលើអចលនទ្រព្យគឺជាពន្ធដែលត្រូវបង់លើអចលនទ្រព្យទាំងអស់ដែលមានកម្មសិទ្ធិក្នុងប្រទេសកម្ពុជា។ ពន្ធនេះធានាបាននូវការចែកចាយការទទួលខុសត្រូវក្នុងការថែរក្សា និងអភិវឌ្ឍហេដ្ឋារចនាសម្ព័ន្ធ។

  • ✓ ផ្ទះ - អចលនទ្រព្យប្រភេទលំនៅឋាន
  • ✓ ដី - ដីសម្រាប់កសិកម្ម ឬវិនិយោគ
  • ✓ អាផាតមិន - អចលនទ្រព្យលំនៅឋានចម្រុះ
  • ✓ ពាណិជ្ជកម្ម - អចលនទ្រព្យសម្រាប់អាជីវកម្ម

២. ច្បាប់ និងបទប្បញ្ញត្តិ

គ្រប់គ្រងដោយច្បាប់ និងអនុក្រឹត្យ ដូចខាងក្រោម៖

  • • ច្បាប់ស្តីពីលក្ខណៈកម្មសិទ្ធិ៖ គ្រឹះនៃប្រព័ន្ធលក្ខណៈកម្មសិទ្ធិកម្ពុជា
  • • អនុក្រឹត្យលេខ ១១៤ (អនក្រ.បក)៖ ការគ្រប់គ្រងពន្ធលើអចលនទ្រព្យ
  • • ប្រកាសលេខ ០១៦ (សហវ.ពដ)៖ មូលដ្ឋាននិងលក្ខខណ្ឌស្តីពីលក្ខណៈកម្មសិទ្ធិ

៣. អត្រាពន្ធតាមប្រភេទ

ពន្ធលើអចលនទ្រព្យត្រូវបានគណនាដោយផ្អែកលើតម្លៃអចលនទ្រព្យ និងប្រភេទរបស់វា។ អត្រាគោលដៅគឺ ០.១% ក្នុងមួយឆ្នាំ។

ផ្ទះលំនៅឋាន ០.១%/ឆ្នាំ
ដី ០.១២%/ឆ្នាំ
អាផាតមិន ០.០៨%/ឆ្នាំ
ពាណិជ្ជកម្ម ០.១៥%/ឆ្នាំ

💡 សម្គាល់៖ សម្រាប់អចលនទ្រព្យដែលមានតម្លៃលើសពី ៥០ លានរៀល អត្រាពន្ធផ្លាស់ប្តូរដូចខាងក្រោម។

4. ប្រព័ន្ធពន្ធតាមដំណាក់កាល (Progressive Tax)

សម្រាប់អចលនទ្រព្យដែលមានតម្លៃខ្ពស់ អត្របង់ពន្ធកើនឡើងដើម្បីធានាភាពយុត្តិធម៌ក្នុងការចែកចាយ។

តម្លៃអចលនទ្រព្យ (រៀល) អត្របង្កើន រូបមន្តគណនា
0 - 50,000,000 រៀល x 1.0 អត្រាគោល
50,000,001 - 100,000,000 រៀល x 1.2 អត្រាគោល × 1.2
លើសពី 100,000,000 រៀល x 1.5 អត្របង្កើន × 1.5

ឧទាហរណ៍ការគណនាពន្ធលើអចលនទ្រព្យ៖

ប្រសិនបើអ្នកមានផ្ទះតម្លៃ 80,000,000 រៀល៖

  • តម្លៃអចលនទ្រព្យ៖ 80,000,000 រៀល
  • ប្រភេទ៖ ផ្ទះលំនៅឋាន
  • អត្របង្កើន៖ x 1.2 (ដោយសារតម្លៃលើសពី ៥០ លាន)
ការគណនាលម្អិត៖ ពន្ធ = 80,000,000 × 0.1% × 1.2 = 96,000 រៀល/ឆ្នាំ

ពន្ធលើអចលនទ្រព្យដែលត្រូវបង់សរុប = 96,000 រៀលក្នុងមួយឆ្នាំ

ចាប់ផ្តើមគណនាពន្ធឥឡូវនេះ ត្រឡប់ទៅកាន់ព័ត៌មានពន្ធ
