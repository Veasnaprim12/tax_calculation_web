អំពីពន្ធលើតម្លៃបន្ថែម (VAT)

ស្វែងយល់អំពីការគណនា ច្បាប់ និងបទប្បញ្ញត្តិពាក់ព័ន្ធនឹងពន្ធលើតម្លៃបន្ថែមនៅក្នុងប្រទេសកម្ពុជា។

១. សេចក្តីសង្ខេបអំពី VAT

ពន្ធលើតម្លៃបន្ថែម (VAT) គឺជាប្រភេទពន្ធលើការប្រើប្រាស់ដែលត្រូវបង់លើតម្លៃបន្ថែមនៃទំនិញ និងសេវាកម្ម។ ពន្ធនេះត្រូវបានគិតពីការលក់ទំនិញ និងសេវាកម្មទាំងអស់ដែលមានការប្រើប្រាស់នៅក្នុងប្រទេសកម្ពុជា។

  • ✓ ត្រូវបង់លើការលក់ទំនិញ និងសេវាកម្ម
  • ✓ ត្រូវបង់ដោយអ្នកលក់ ប៉ុន្តែអ្នកទិញទទួលខុសត្រូវ
  • ✓ ត្រូវបង់ទៅរដ្ឋាភិបាលតាមរយៈការប្រមូលពន្ធ

២. ច្បាប់ និងបទប្បញ្ញត្តិ

គ្រប់គ្រងដោយច្បាប់ និងអនុក្រឹត្យជាធរមាន៖

  • • ច្បាប់ស្តីពីសារពើពន្ធ៖ ច្បាប់គ្រឹះនៃប្រព័ន្ធពន្ធដារកម្ពុជា
  • • អនុក្រឹត្យលេខ ០១៣០ អនក្រ.បក (២០២៤)៖ ការកែប្រែពន្ធលើតម្លៃបន្ថែម
  • • សារាចរណែនាំលេខ ០០៧ សហវ (២០២៣)៖ ការអនុវត្តពន្ធលើតម្លៃបន្ថែម

៣. ទំនិញ និងសេវាកម្មជាប់ពន្ធ

ទំនិញ និងសេវាកម្មដែលត្រូវបង់ពន្ធលើតម្លៃបន្ថែម៖

ទំនិញស្តង់ដារ 10%
ទំនិញនាំចូល 5%
ទំនិញអាហារូបករណ៍ 0%

💡 សម្គាល់: ពន្ធត្រូវបានគិតលើតម្លៃលក់ចុងក្រោយ ហើយត្រូវបង់ដោយអ្នកទិញ។

4. អត្រាពន្ធតាមប្រភេទទំនិញ/សេវាកម្ម

អត្រាពន្ធលើតម្លៃបន្ថែមត្រូវបានកំណត់ដោយផ្អែកលើប្រភេទទំនិញ និងសេវាកម្ម។ អត្រាគោលគឺ 10% សម្រាប់ទំនិញស្តង់ដារ។

ប្រភេទទំនិញ/សេវាកម្ម អត្រាពន្ធ ឧទាហរណ៍
ទំនិញស្តង់ដារ 10% គ្រឿងអេឡិចត្រូនិក គ្រឿងសម្លៀកបំពាក់ គ្រឿងក្លៀវ
ទំនិញនាំចូល 5% ទំនិញនាំចូលពីបរទេស
ទំនិញអាហារូបករណ៍គ្រប់គ្រង 0% ស្រូវ បន្សាប បន្សាដី ទឹកស្អាត
សេវាកម្មគ្រប់គ្រង 0% សេវាកម្មវេជ្ជសាស្ត្រ អប់រំ

ឧទាហរណ៍ការគណនាពន្ធលើតម្លៃបន្ថែម:

ប្រសិនបើអ្នកទិញទំនិញមួយដែលមានតម្លៃ 1,000,000 រៀល (រួមបញ្ចូល VAT 10%)៖

  • តម្លៃទំនិញមិនរួមបញ្ចូល VAT៖ 1,000,000 ÷ 1.10 = 909,091 រៀល
  • ពន្ធលើតម្លៃបន្ថែម (VAT 10%)៖ 909,091 × 10% = 90,909 រៀល
  • តម្លៃសរុបដែលត្រូវបង់៖ 909,091 + 90,909 = 1,000,000 រៀល
រូបមន្តគណនាពន្ធ: VAT = តម្លៃទំនិញ × អត្រា VAT
តម្លៃសរុប = តម្លៃទំនិញ + VAT

ឧទាហរណ៍៖ 909,091 × 10% = 90,909 រៀល (VAT)

៥. អ្នកជាប់ពន្ធ VAT

អ្នកដែលត្រូវចុះឈ្មោះជាអ្នកជាប់ពន្ធលើតម្លៃបន្ថែម៖

  • ✓ អ្នកធ្វើពាណិជ្ជកម្មដែលមានចំណូលប្រចាំឆ្នាំ > 125,000,000 រៀល
  • ✓ អ្នកនាំចូលទំនិញពីបរទេស
  • ✓ អ្នកផ្តល់សេវាកម្មដែលចុះឈ្មោះជាប់ពន្ធ

៦. ការចុះឈ្មោះ VAT

ដំណើរការចុះឈ្មោះជាអ្នកជាប់ពន្ធលើតម្លៃបន្ថែម៖

  • • ជំហានទី 1: បំពេញទម្រង់ចុះឈ្មោះ VAT
  • • ជំហានទី 2: ដាក់ពាក្យស្នើសុំទៅការិយាល័យពន្ធ
  • • ជំហានទី 3: ទទួលបានលេខសម្គាល់អ្នកជាប់ពន្ធ (TIN)

៧. ការប្រមូលពន្ធ

របៀបប្រមូល និងបង់ពន្ធលើតម្លៃបន្ថែម៖

រយៈពេលប្រមូល ប្រចាំខែ
រូបមន្តគណនា VAT = Output - Input
ការបង់ពន្ធ តាមអនឡាញ/ធនាគារ

⚠️ សម្គាល់: អ្នកជាប់ពន្ធត្រូវដាក់ពាក្យប្រមូលពន្ធប្រចាំខែ ទោះបីជាមិនមានការលក់ក៏ដោយ។
