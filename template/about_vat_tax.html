អំពីពន្ធលើក្រុមហ៊ុន

ស្វែងយល់អំពីការគណនា ច្បាប់ និងបទប្បញ្ញត្តិពាក់ព័ន្ធនឹងពន្ធលើក្រុមហ៊ុន​​​ (VAT) នៅក្នុងប្រទេសកម្ពុជា។

១. សេចក្តីសង្ខេបអំពីពន្ធលើតម្លៃបន្ថែម

ពន្ធលើតម្លៃបន្ថែម (VAT - Value Added Tax) គឺជាពន្ធលើការប្រើប្រាស់ដែលត្រូវបង់ក្នុងពេលលក់ទិន្នន័យ ឬផ្តល់សេវាកម្ម។ នេះគឺជាពន្ធសាធារណៈដ៏សំខាន់ដែលប៉ះពាល់ដល់ច្បាប់ពាណិជ្ជកម្ម និងប្រជាជនទូទៅ។ វាត្រូវបានគណនាដូចខាងក្រោម៖

  • ✓ អត្រាមាតិលោក (Standard Rate): ១០%
  • ✓ អ្នកលក់អាចកាត់បន្ថយក្នុងបន្ទុក VAT បានលើការទិញទិន្នន័យ និងសេវាកម្ម
  • ✓ មានការលើកលែង VAT សម្រាប់អាហារូបករណ៍ និងផលិតផលជាក់លាក់

២. ច្បាប់ និងបទប្បញ្ញត្តិ

គ្រប់គ្រងដោយច្បាប់ និងអនុក្រឹត្យជាធរមាន៖

  • • ច្បាប់ស្តីពីពន្ធលើតម្លៃបន្ថែម៖ ច្បាប់គ្រឹះសម្រាប់ប្រព័ន្ធ VAT នៅកម្ពុជា
  • • អនុក្រឹត្យលេខ ឆ្នាំ (បច្ចុប្បន្ន)៖ ការកែប្រែ និងការបង្ហាញលម្អិតច្បាប់
  • • សារាចរណែនាំរបស់មន្ត្រីពន្ធដារ៖ លម្អិតលម្អិតអំពីនីតិវិធីចុងក្រោយ និងលក្ខណៈលម្អិត
  • • នីតិវិធីឯកសារ៖ ទាំងឯកសារគ្រប់ប្រភេទសម្រាប់ការលើកលែង ឬរាយការណ៍ VAT

៣. ឯកសារ និងការលើកលែង VAT

ផលិតផល និងសេវាកម្មខាងក្រោមត្រូវបានលើកលែងពី VAT៖

អាហារូបករណ៍គ្រឹត្យចត្រ

ចាប់រាប់ដូចជា អង្ករ ដាំឹង ម្សៅប្រេង ទឹក នោះសមរភូមិនិងផលិតផលក្រុមគ្រឺប៉ាល់ផ្សេងទៀត

ផលិតផលថាំទង់

ផលិតផលក្រុមថាំទង់នឹងផលិតផលដែលគ្រប់គ្រងដោយក្រសួងសុខាភិបាល

សេវាកម្មបច្ចេកទេស និងសិក្សា

សេវាកម្មផ្សេងៗដែលគ្រប់គ្រងដោយរាជរដ្ឋាភិបាល ឬស្ថាប័នអប់រEducation

💡 សម្គាល់: អ្នកលក់ដែលមាន turnover ទាបក៏ដោយក៏អាចរៀបចំឯកសារដែលលើកលែង VAT បានដែរ។

4. អត្រា និងការគណនា VAT

ពន្ធលើតម្លៃបន្ថែម (VAT) នៅកម្ពុជាត្រូវបានគណនាដូចខាងក្រោម៖

ប្រភេទ អត្រា រូបមន្តគណនា
អត្រាមាតិលោក ១០% VAT = តម្លៃលក់ × ១០%
តម្លៃលក់ឈរសម (Taxable) គាស់ តម្លៃលក់មូលដ្ឋាននៃពន្ធ = តម្លៃលក់អាល់ដែលមាន VAT
ការលើកលែង ០% ផលិតផលក្រុមក្រុមដែលលើកលែងមិនមាន VAT

ឧទាហរណ៍ការគណនា VAT៖

ប្រសិនបើតម្លៃលក់របស់អ្នក 10,000,000 រៀល (មិនរាប់ VAT)៖

  • តម្លៃលក់មូលដ្ឋាន៖ 10,000,000 រៀល
  • ពន្ធលើតម្លៃបន្ថែម (10%)៖ 10,000,000 × 10% = 1,000,000 រៀល
  • តម្លៃលក់សរុប (រួម VAT)៖ 10,000,000 + 1,000,000 = 11,000,000 រៀល
ការគណនា៖ VAT = 10,000,000 × 10% = 1,000,000 រៀល

ក្រុមហ៊ុនឬតម្លៃលក់ត្រូវបង់ វិក្កយបត្រសរុប = 11,000,000 រៀល

ចាប់ផ្តើមគណនាពន្ធឥឡូវនេះ ត្រឡប់ទៅកាន់ព័ត៌មានពន្ធ
